# Discrete Data Modeling with Optimal Variable Selection via Cross-Validation

Code and data for the paper

> Paulo, D. G., Conceição, K. S. and Andrade, M. G. *Discrete Data Modeling with
> Optimal Variable Selection via Cross-Validation*. Communications in Statistics:
> Case Studies, Data Analysis and Applications (submitted).

The repository contains the R code and data needed to reproduce the two
simulation studies (Section 5) and the real data application (Section 6) of the
paper.

## Overview

The paper proposes a framework for variable selection and predictive assessment
in count data regression models of the Power Series (PS) family:

1. **Predictor selection:** best subset selection embedded in *k*-fold
   cross-validation (Algorithm 1), with squared error loss.
2. **Model comparison:** a Friedman test, corrected for the dependence among
   folds induced by overlapping training sets, with Holm-adjusted pairwise
   comparisons.
3. **Distribution choice:** the Bayesian information criterion (BIC).

The Poisson (P), negative binomial (NB) and generalized Poisson (GP) models are
fitted by maximum likelihood: the Poisson model with `glm.fit`, and the NB and
GP models with `nloptr` (algorithm `NLOPT_LD_LBFGS`, analytical gradient,
dispersion parameterized as `log(phi)` in `[-10, 10]`).

## Requirements

- R >= 4.5.1
- R package `nloptr` (version 2.2.1 was used)
- Base R package `parallel` (included with R)

```r
install.packages("nloptr")
```

## Reproducing the results

Set the working directory to the root of the repository before running the
scripts. All random seeds are fixed in the scripts, so the results are
reproducible.

### First simulation study (Sections 5.1-5.4, Tables 5-8)

```r
source("R/simulacao_secao5.R")
```

- Training samples of size n = 2000, independent test samples of size 5000.
- R = 100 replications for each true distribution (P, NB, GP).
- Each replication requires 10,512 model fits.
- Running time: about 3 hours on 7 cores.

### Second simulation study (Section 5.5, Tables 9-12)

```r
source("R/simulacao_secao5_estudo2.R")
```

- Training samples of size n = 500, 2000 and 10,000, with corr(X1, X2) = 0.7.
- Independent test samples of size 5000; R = 100 replications for each
  combination of sample size and true distribution.
- Running time: about 1 hour (n = 500), 3 hours (n = 2000) and 14 hours
  (n = 10,000) on 7 cores.

### Real data application (Section 6, Tables 13-16, Figure 2)

```r
source("R/aplicacao_secao6.R")
source("R/salvar_resultados_secao6.R")
```

### Parallel execution and resuming

The simulation scripts run in parallel with a PSOCK cluster
(`parallel::makeCluster`), which works on Windows, macOS and Linux. Set the
number of cores at the top of each script. Each replication is saved as a
separate `.rds` file, so an interrupted run resumes from where it stopped. Set
`FRESH <- TRUE` to delete previous results and start again.

The individual replication files (`sim_out/`, `sim2_out/`) are not included in
the repository because of their number; they are regenerated by the scripts.
The summary files in `results/` contain all the information used to build the
tables of the paper.

## Data

The data used in Section 6 are a processed subset of the *Diabetes 130-US
Hospitals for Years 1999-2008* database, with 25,000 hospital encounters of
patients aged 40 years or older. See `data/README_data.md` for the source, the
license and the description of the variables.

- Clore, J., Cios, K., DeShazo, J. and Strack, B. (2014). Diabetes 130-US
  Hospitals for Years 1999-2008. UCI Machine Learning Repository.
  https://doi.org/10.24432/C5230J
- Strack, B. et al. (2014). Impact of HbA1c measurement on hospital readmission
  rates: analysis of 70,000 clinical database patient records. *BioMed Research
  International*, 2014, 781670.
